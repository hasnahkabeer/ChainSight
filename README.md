# 🔗 ChainSight – AI-Powered Supply Chain Risk Prediction & Analytics

**ChainSight** is an interactive AI-powered supply chain analytics platform designed to identify potential supply chain disruptions, predict inventory risks, and support data-driven business decisions.

The platform transforms supply chain data into actionable insights through interactive dashboards, predictive machine learning models, and risk analysis.

## 🚀 Project Overview

Supply chains face several challenges, including delivery delays, inventory shortages, supplier disruptions, and unexpected operational risks.

ChainSight addresses these challenges by combining data analytics and machine learning to help identify potential risks before they significantly affect business operations.

It provides a centralized dashboard to monitor supply chain performance, analyze supplier risks, and predict inventory-related problems.

## ✨ Key Features

- 📊 **Supply Chain Analytics:** Interactive dashboard displaying important supply chain performance metrics.
- 🚚 **Delivery Delay Analysis:** Identifies delayed orders and analyzes delivery performance.
- 🏭 **Supplier Risk Analysis:** Evaluates supplier-related risks and operational performance.
- 🤖 **AI-Based Risk Prediction:** Uses machine learning to predict potential inventory and supply chain risks.
- 📦 **Inventory Risk Monitoring:** Identifies potential inventory shortages by analyzing inventory availability and delivery timelines.
- ⚡ **Disruption Simulator:** Helps explore possible supply chain disruption scenarios.
- 📁 **CSV Data Upload:** Allows users to upload supply chain datasets for analysis.
- 📈 **Data Visualization:** Presents insights through interactive charts and visual reports.

## 🧠 Machine Learning

ChainSight incorporates machine learning to identify potential inventory and supply chain risks.

The prediction workflow involves:

1. Supply chain data collection.
2. Data preprocessing and feature preparation.
3. Machine learning model training.
4. Risk prediction using trained models.
5. Displaying predictions and insights through the dashboard.

The objective is to support proactive decision-making rather than relying only on historical performance reports.

## 🏗️ System Workflow

1. Upload or load supply chain data.
2. Process and analyze the dataset.
3. Calculate important operational metrics.
4. Evaluate delivery and supplier performance.
5. Apply machine learning models for risk prediction.
6. Display insights, predictions, and potential disruptions through the dashboard.

## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/ChainSight.git
```

### 2. Navigate to the project directory

```bash
cd ChainSight
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the application

```bash
streamlit run app.py
```

### 5. Open the application

Streamlit will provide a local URL, usually:

```text
http://localhost:8501
```
